Modos de um sistema diagonalizável

Os autovetores separam o sistema em direções independentes.

Pré-requisitos: Autovalores, base de autovetores e equações escalares u′=λuu'=\lambda u.

Enunciado

Se uma matriz real AA tem base real de autovetores v1,…,vnv_1,\ldots,v_n, com Avj=λjvjAv_j=\lambda_j v_j, cada solução de x′=Axx'=Ax é ∑j=1ncjeλj(t−t0)vj\sum_{j=1}^n c_j e^{\lambda_j (t-t_0)}v_j, onde cjc_j são as coordenadas de x(t0)x(t_0) nessa base.

Ideia da prova

Expresse o vetor solução na base própria e compare os coeficientes.

Demonstração

Na base dada, escreva x(t)=∑uj(t)vjx(t)=\sum u_j(t)v_j. As coordenadas são diferenciáveis, pois são aplicações lineares fixas de x(t)x(t). Igualando x′=∑uj′vjx'=\sum u_j'v_j e Ax=∑λjujvjAx=\sum \lambda_ju_jv_j, obtemos uj′=λjuju_j'=\lambda_j u_j. Pelo fator e−λjte^{-\lambda_j t}, cada solução escalar é cjeλj(t−t0)c_j e^{\lambda_j(t-t_0)}. A substituição direta verifica qualquer combinação resultante.

Exemplo

Se A=(2112)A=\begin{pmatrix}2&1\\1&2\end{pmatrix}, os vetores (1,1)(1,1) e (1,−1)(1,-1) têm autovalores 33 e 11. Para dado (2,0)(2,0) em t0=0t_0=0, a solução é e3t(1,1)+et(1,−1)e^{3t}(1,1)+e^t(1,-1).

Atenção

Se não existe base real de autovetores, a receita não fornece todas as trajetórias; pode ser necessário usar blocos reais associados a raízes complexas ou cadeias generalizadas.

Complemento

Estabilidade. Se todos os λj\lambda_j são negativos, toda solução tende a zero; se algum é positivo, existem soluções ilimitadas.

Sem base de autovetores. Para A=(0100)A=\begin{pmatrix}0&1\\0&0\end{pmatrix}, há um só autovetor independente e a solução (a+tb,b)(a+tb,b) não é soma de exponenciais. A rotação (0−110)\begin{pmatrix}0&-1\\1&0\end{pmatrix} não tem autovetor real.
