# Teoremas em prova

Coleção de 200 teoremas de matemática, organizada em dez áreas. Cada página apresenta um enunciado, uma demonstração, um exemplo e referências.

## Como consultar

Baixe ou clone o repositório e abra [`index.html`](index.html) no navegador. As fórmulas e a busca funcionam offline. O [`catalogo.csv`](catalogo.csv) relaciona os teoremas e seus arquivos. A revisão matemática e visual está registrada em [`REVISAO.txt`](REVISAO.txt) e [`auditoria.csv`](auditoria.csv).
